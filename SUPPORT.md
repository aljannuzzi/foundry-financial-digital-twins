# Support

## Start here

Read the [README](README.md), detailed [documentation](docs/architecture.md),
and [known limitations](docs/simulation-card.md) before requesting help.

## Questions and defects

After the repository becomes public, use the appropriate GitHub issue template
for:

- reproducible defects in the reference implementation;
- documentation corrections;
- bounded feature proposals consistent with synthetic scenario testing.

Include operating system, runtime versions, engine, minimal reproduction, and
sanitized logs. Never include customer data, personal data, tenant details,
credentials, tokens, internal URLs, or confidential information.

Maintenance is best effort with no response-time or support SLA. For Azure
service incidents, quota, billing, or account issues, use official Azure support
channels.

## Unsupported requests

This project does not provide production deployment approval, financial advice,
regulatory interpretation, model validation, or support for real customer data
and consequential financial decisioning.

## Security

Do not open a public issue for a vulnerability. Follow
[SECURITY.md](SECURITY.md) and use GitHub private vulnerability reporting.
