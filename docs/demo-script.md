# Demo Script

[Back to the README](../README.md)

## 1. Frame the problem

> An Agro segment is not a person. If we configure a product only around the
> average, which customers are we ignoring?

Immediately state: **this is a synthetic scenario, not a forecast**.

## 2. Show the pipeline

Open the flow:

`synthetic usage → features → hypotheses → profile → decision`

Select one profile and show:

- seasonality;
- working-capital pressure;
- channel behavior;
- hypothesis score and confidence;
- evidence IDs.

Explain that observations, derived values, uncertain hypotheses, treatments,
responses, and audit attributes are separate layers.

## 3. Show heterogeneity

For the same variant, select:

- one agent that accepts;
- one that considers;
- one that requests a change;
- one that rejects.

Emphasize that all belong to the same fictional Agro segment but have different
synthetic histories and constraints. The behavioral anchor is an exploratory
navigation aid, not a true personality label.

## 4. Run a counterfactual

Choose `Agro Flex Digital Rewards`.

1. increase the monthly fee;
2. increase the grace period;
3. keep cashback unchanged;
4. run the replay.

Show:

- the population and seed did not change;
- which agents changed choice;
- differences by anchor;
- structured reasons and evidence IDs;
- the recorded engine and scenario hash.

## 5. State the scientific limit

Show the persistent disclaimer and say:

> The laboratory does not predict sales. It narrows hypotheses. The next step is
> to design a real pilot capable of falsifying or confirming the signals.

Do not describe `fit_score` as purchase probability or aggregate acceptance as
expected demand.

## 6. Describe the future, separately

Present the customer-authorized preference proxy:

> The same engineering foundation might one day represent a customer for that
> customer, but only with objectives, consent, identity, and permissions
> separated from the bank's interests.

Make clear that this proxy is not implemented.

## Close

> First, agents help us question a synthetic market. Then, properly governed
> research in the real market determines whether those agent signals deserve
> any trust.
