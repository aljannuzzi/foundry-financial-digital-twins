# Code of Conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Be respectful, assume good intent, welcome constructive technical disagreement,
and do not harass or discriminate.

The code applies in repository spaces and when representing the project.
Maintainers may edit or remove contributions and restrict participation when
behavior is inappropriate.

Use GitHub's private **Report content** flow or
[GitHub Support](https://support.github.com/contact/report-abuse) for conduct
concerns. Do not publish personal or sensitive details in an issue. Reports will
be handled as privately and promptly as the available channel permits.
